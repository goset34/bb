# Glosario de nombres originales

STRATA replica mecánicas, pero **no usa marcas ni términos acuñados** por el juego de
referencia. Los términos genéricos del idioma (piedra, hierro, zombi, esqueleto, aldeano,
bruja, élitros, tótem…) se conservan; los términos acuñados se sustituyen por nombres
propios. Esta tabla sirve para la auditoría de contenido (`AUDIT.md`).
